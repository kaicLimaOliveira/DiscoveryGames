# ADR 0004 — TikTok em modo manual assistido

- **Status:** aceito (2026-11-15)
- **Contexto:** a Content Posting API do TikTok classifica como não aceitáveis ferramentas para postar em contas geridas pela própria equipe e apps de uso privado; sem auditoria, posts só ficam privados. A rota adequada para contas próprias (Accounts API da TikTok API for Business) exige registro do desenvolvedor como empresa (e-mail corporativo + site próprio), requisito que a operação não atende hoje. Ver [tiktok.md](../07-integracoes/tiktok.md).
- **Decisão:** o TikTok é atendido pelo **modo manual assistido**: a central gera rendition e legenda específicas, agenda, notifica no horário; uma pessoa baixa o vídeo, copia o texto, posta no app e cola a URL. Métricas do TikTok: registro manual opcional. Nenhuma credencial do TikTok no sistema.
- **Alternativas:** Direct Post auditado (alto risco de reprovação pelo enquadramento); Upload para inbox (mesma revisão e enquadramento); Accounts API (melhor tecnicamente, bloqueada pelos requisitos de registro); automação de navegador (proibida pelo briefing).
- **Consequências:** ~2 min de trabalho manual por vídeo; sem métricas automáticas do TikTok; sem bucket público de entrega; menos escopo nas Fases 7 e 9. **Gatilho de revisão:** empresa passa a ter CNPJ/e-mail corporativo/site → implementar a Accounts API como novo modo do mesmo adaptador (exige bucket de entrega com domínio verificado). **Atenção (monetização):** a API for Business exige conta TikTok Business, que **não é elegível ao Creator Rewards Program** → só migrar se a receita do TikTok vier de parcerias com marcas, não do Creator Rewards ([20 §2.2](../20-monetizacao.md)).
